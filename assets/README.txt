================================================================================
CAMPUS BONDHON - ASSETS FOLDER (assets/)
Team Name: Bondhon
================================================================================

Place your custom images and university logo inside this `assets/` folder:

1. `hero-campus.jpg`       -> Main hero image on the Home Page (`index.html`)
2. `study-default.jpg`     -> Default fallback photo for Study Resources
3. `clothing-default.jpg`  -> Default fallback photo for Clothing Resources
4. `housing-default.jpg`   -> Default fallback photo for Landlords Profile
5. `logo.png` (optional)   -> If you want to replace the "CB" badge in the navbar
                              with an image logo, add `assets/logo.png` here.
